**核心新增证据**：
- **确定性计数器**：base 与 patched 的 `SEEK_POSITIONS`(1,622,016) / `GROUP_UNPACKS`(12,672) /
  `GROUP_CHECKS`(1,622,016) **逐项相同**；disjoint 上 patched 的 `ANCHOR_ITERS`/`BINARY_SEARCHES`
  比 base **更少**（264/0 vs 528/528）→ 1.44× 与逻辑无关是**实证**。
- **GOL**：`GROUP_CHECKS` 精确降到 **1/128**，`SEEK_POSITIONS`/`GROUP_UNPACKS` 不变。
- **独立对抗式检视**：语义等价（映射证明 + 3616 万组 `(total,start,end)` 穷举零分歧），
  并指出我计数器插在热循环内的**方法论问题**（已量化 2.17× 开销）、
  以及"removes a division"的**过度表述**（128 是 2 的幂，本来就是移位）。
- **e2e 全量 943 条**：base 1.000× / patched 0.990× / **GOL 0.989×（胜出 375 条最多）**，
  **TOP_10 差异 0 条**。

## 两条结论（一句话）

1. **classic 的 1.16–1.44× 是前端 op-cache 的布局伪影**：同一份机器码、同样的指令/分支/缓存/频率，
   只因热函数的落点不同，op-cache miss 差 3.5×。**没有逻辑缺陷**（decode 占 86–99.6%）。
   确定性对策 = 在热循环前 `asm!(".p2align 6")`（tag `pr9170-align-fix`，实测 1.43× → 0.99×）。
2. **`"york photo"` 的 1.342× 在本机不复现**（1.013×），且 300 条 phrase 全量最差只有 1.065×、
   结果逐位一致；base 跨机差 1% 而 patched 差 34% → 与 classic 同源的布局伪影。
